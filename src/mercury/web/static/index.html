    How to fill a two-endpoint assessment
    1. Start a Mercury agent on both endpoints using their reciprocal peer configuration files.
    2. Configuration path: the local endpoint's peer JSON file. Identity and peer address must exactly match values already fixed in that file.
    3. Profiles: choose only profiles enabled in that peer configuration. Use the local and peer CIDRs only to explain whether ARP/ND is applicable.

    Mapping accepts only private ranges and fixed profiles. Native Nmap profiles never accept free-form arguments. Duration 0 means no added operator cutoff, within hard ceilings.

    Coverage reports the tested profile, direction, packet shape and time window; it does not claim every possible tunnel has been excluded.
