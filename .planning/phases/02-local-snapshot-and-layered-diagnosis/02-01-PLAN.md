Create `src/mercury/platform/` as an internal concrete package, not a plugin
API. In `common.py`, add frozen slotted `CommandResult`, `RouteRecord`, and
`DnsServerRecord` values with exact validation:

- command argv is a non-empty tuple of non-empty strings;
- return code is `int | None`; `None` is reserved for missing/timeout;
- decoded stdout/stderr are bounded to 262,144 bytes each before parsing;
- diagnostic snippets stored in evidence are sanitized with the existing
  history helpers and capped at 1,024 characters;
- routes carry family 4/6, canonical destination prefix, optional canonical
  gateway, interface name/index, separate route/interface metrics, and source;
- DNS records carry family 4/6, canonical address including a separately
  validated IPv6 scope when present, interface name/index, and source.

Implement one async `run_command(argv, timeout_s=5.0,
max_output_bytes=262144)` using `asyncio.create_subprocess_exec(*argv)` with
`stdout/stderr=PIPE`, never `shell=True`. Read incrementally so the byte ceiling
is enforced during execution. The shared process boundary serves both passive
inventory and diagnosis, so before process creation require a non-boolean
finite numeric `0.1 <= timeout_s <= 30.0`, and reject a boolean/non-integer/non-positive
`max_output_bytes` or any value above 262,144. Create both pipe-reader tasks under one owner
and use one shared bounded termination routine for timeout, output overflow,
and owning-coroutine cancellation. That routine preserves the primary
outcome, kills the child if still live, cancels and awaits both stdout/stderr
reader tasks, closes/drains owned pipe transports where supported, and
boundedly awaits child reaping before returning or re-raising cancellation.
No timeout, overflow, or cancellation path may leave a process, reader task,
or unread owned pipe alive.
Return typed missing-tool, permission, timeout, nonzero, and overflow outcomes
without raising localized process text across the boundary.

Keep the stricter passive contract at the callers: every route/DNS inventory
adapter must pass a finite timeout no greater than `5.0` seconds and reject
`5.001` before calling `run_command`. The shared runner itself must accept
`5.001` and the exact diagnosis maximum `30.0`; it must not silently shorten
either value.

In `platform/__init__.py`, dispatch directly on `sys.platform` to
`windows.collect_platform`, `linux.collect_platform`, or
`macos.collect_platform`; unsupported platforms return explicit unsupported
capabilities. Do not add an abstract base class, factory, registry, entry-point
plugin, or global subprocess mock. Start `tests/test_platforms.py` with
constructor, timeout, overflow, missing executable, permission, Unicode, NUL/
control sanitization, and direct-dispatch tables using injected command
results—no native command is run by normal unit tests.

`RouteMetric`, `InterfaceMetric`, protocol/state, and every IPv4/IPv6 default.
DNS comes from `Get-DnsClientServerAddress`; retain interface/family/source and
all configured addresses while distinguishing inactive/tunnel/legacy rows.

`0.1..5.0` to the shared 0.1..30.0-second `run_command` boundary; no passive
source may select or inherit a timeout above 5 seconds.

`ip -j -6 route show table all`. Missing/malformed `ip` is explicit route
degradation. DNS always parses bounded `/etc/resolv.conf` `nameserver` entries
without following arbitrary includes; `127.0.0.53` remains a local stub with a

--no-pager` returns valid JSON, enrich per-link records; otherwise retain
resolv.conf facts and an independent enrichment capability error.

`/sbin/route -n get -inet6 default`,
`/usr/sbin/netstat -rn -f inet`, `... -f inet6`, and
`/usr/sbin/scutil --dns`. Parse field/block fixtures rather than fixed columns;
an absent IPv6 default or malformed resolver block degrades only that source.

Add sanitized fixtures covering empty/one/many records, CRLF/LF, Unicode
aliases, VPN/tunnel interfaces, multiple IPv4/IPv6 defaults, on-link routes,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native OS process/file output -> platform parser | Local but untrusted/malformed/locale-sensitive bytes cross into canonical records |
| psutil/native facts -> public TaskResult | Potentially sensitive host/network facts cross into serializable evidence |
| Route/gateway evidence -> topology conclusion | Inference could be falsely promoted to switch identity |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T02-01 | Tampering/Elevation | `platform.common.run_command` and Windows scripts | mitigate | Fixed executable/argv and constant PowerShell scripts; no `shell=True` or user interpolation; parser validation at entry |
| T02-07 | Denial of service | Native stdout/stderr and record cardinality | mitigate | Shared 0.1..30.0-second command boundary, passive caller cap of 5.0 seconds, 262144-byte stream caps, and one timeout/overflow/cancellation termination routine that kills/reaps the child and cancels/awaits both readers |
| T02-08 | Information disclosure | Native diagnostics and inventory result | mitigate | Normalized allowlisted facts, 1024-character sanitized diagnostics, no raw dump/body/header/credential persistence |
| T02-10 | Spoofing/Repudiation | Gateway/route-to-switch interpretation | mitigate | Dedicated unavailable access-switch observation and regression that gateway/route cannot satisfy it |
</threat_model>
