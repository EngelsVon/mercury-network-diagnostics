Upgrade the Phase 1 evidence, plan, admission, and persistence boundary so
Phase 2 probes can be represented honestly and executed under exact budgets.

Purpose: DNS, TLS, HTTP, native ping, and native path cannot safely be added
while the canonical plan assumes a target x port x transport Cartesian product,
the reader accepts arbitrary future minors, and runners can choose their own
probe label or observation cardinality.

and digest binding, per-step reservations, authoritative preflight/evidence
binding, safe history projection, and adversarial foundation tests. This plan
does not implement profiles, real protocol/native runners, diagnosis
classification, application facade, or CLI commands.
