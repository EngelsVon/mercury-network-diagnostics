<task type="auto">
  <name>Task 3: Bounded local SQLite history</name>
  <files>src/mercury/history.py, tests/test_history.py</files>
  <action>
Create a minimal numbered SQLite schema for tasks (request, effective plan,
status, progress, result, timestamps) and events (task-local sequence, type,
bounded payload). Use transactions, foreign keys, WAL where appropriate, and
parameterized SQL. Default to the platform user-data directory but accept an
explicit path for tests. Attempt mode 0600 on POSIX. Reject dictionaries/JSON

event replay plus deterministic max-count/max-age pruning without an ORM.

Run `python -m unittest tests.test_history -v`.
  </verify>
  <done>

eligible old rows, and never stores tokens/private-key-shaped values.
  </done>
