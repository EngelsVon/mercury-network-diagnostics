<task type="auto">
  <name>Task 1: Canonical target and authorization policy</name>
  <files>src/mercury/policy.py, tests/test_policy.py</files>
  <action>
Parse strict IPv4, IPv6, CIDR, and IDNA hostnames without accepting URLs,
credentials, ambiguous numeric forms, or hidden ports. Preserve and validate a
separate scope/interface ID for IPv6 link-local literals and reject scope IDs
on other addresses. Return typed canonical targets. Model scope grants with normalized networks/names,
ports, transports, expiry, purpose, and authorization attestation. Require
authorization for all non-loopback active work. Inject the resolver; authorize
the name and then every resolved address at use time. Test IPv4-mapped IPv6,
private/public/link-local/multicast/unspecified boundaries, duplicate/canonical
CIDRs, expired grants, and a simulated DNS answer change.
  </action>
  <verify>
Run `python -m unittest tests.test_policy.TargetPolicyTests -v`.
  </verify>
  <done>
No unparsed string or resolver answer can reach a future socket without an
explicit matching decision; scoped link-local targets are either usable as
typed values or produce an explicit unsupported capability.
  </done>
</task>

<task type="auto">
  <name>Task 2: Immutable plan and multi-dimensional ceilings</name>
  <files>src/mercury/planner.py, tests/test_policy.py</files>
  <action>
Implement frozen BudgetLimits, PlanCost, PlanStep, and ProbePlan values. Enforce
the exact absolute ceilings from CONTEXT.md and lower defaults. Treat rate as
logical attempt admission, UDP packet/bytes as Mercury-generated datagrams and
payload, and stream protocols as logical attempts/application bytes; never
claim exact on-wire accounting. Use checked integer multiplication/addition
for target × port × transport × payload ×
retry work. Include packet/byte and global/per-target rate limits even before
UDP probes exist. Enforce confirmation phrases for full TCP and custom UDP.
Expose a serializable preview with warnings and worst-case duration before any
runner is invoked.
  </action>
  <verify>
Run `python -m unittest tests.test_policy.BudgetTests -v`.
  </verify>
  <done>
A full single-host TCP plan can be represented, but oversized multi-dimensional
plans, negative/zero limits, overflow attempts, and confirmation bypasses are
rejected deterministically.
  </done>
</task>

<task type="auto">
  <name>Task 3: Cancellable persisted task lifecycle</name>
  <files>src/mercury/tasks.py, tests/test_tasks.py</files>
  <action>
Implement one TaskService with validated pending→running→completed/failed/
cancelled transitions, task-local monotonic events, aggregate progress, and a
CancellationToken. The service accepts only a compiled ProbePlan. A bounded
synthetic runner yields observations without network I/O and checks
cancellation before admitting each step. Persist accepted state and terminal
partial results through HistoryStore. Bound event count/output and convert
unexpected runner errors into structured error observations without losing
prior evidence.

  <verify>
Run `python -m unittest tests.test_tasks -v`.
  </verify>
  <done>

completed synthetic observations, and is visible after reopening history.
  </done>
