<interfaces>
PairedEndpoint contains configured identity, numeric address, selected TCP
port, and selected UDP port. PairedLease contains plan ID, correlation,
expiry, endpoint, authenticated peer source, UDP nonce, and fixed opaque tag.

PairedListenerService receives an already locally revalidated immutable
ProbePlan, authenticated peer configuration/source, and TaskContext. It derives
bind address, ports, and reverse destination only from these values. Its
observable output is canonical observations/capabilities, never raw packets.
If existing TaskContext.record cannot represent inbound arrived/replied phases,
add one narrow equivalent validation extension; do not bypass admit, record,
reservations, persistence safety, or ceiling enforcement.
</interfaces>
