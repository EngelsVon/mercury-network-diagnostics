<interfaces>
PairedRequest contains only operator configuration paths/identity reference,
the fixed built-in paired profile, explicit authorization/confirmation, and a
finite timeout. It has no remote target, CIDR, port, or payload selector.

MercuryApplication supplies start_agent(config) and run_paired(request).
paired_matrix(result) produces deterministic PairedMatrixRow values and
render_paired(result) projects them. Both endpoints independently recompile
and revalidate current ScopeGrant, time, budgets, and DNS facts before
TaskService admission. The result remains one canonical TaskResult; matrix
rows are pure projections from cited endpoint-labelled observations. CLI
accepts paths and explicit unsafe-development only, never secret contents, and
does no resolver/socket/listener/probe work.
</interfaces>
