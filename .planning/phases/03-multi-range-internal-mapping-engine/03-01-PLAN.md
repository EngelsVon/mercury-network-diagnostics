<objective>
Compile and execute one immutable, aggregate-bounded internal mapping/coverage
plan from multiple private IPv4 CIDRs and the Phase 2 finite profile matrix.

Purpose: operators need one reproducible assessment request rather than many
uncoordinated scans, while retaining exact accounting of target, port, profile,
direction, payload metadata, rate, concurrency and stop reason.

Output: a typed multi-range request, canonical aggregate plan, rate/concurrency
scheduler, zero-duration semantics and bounded task/history evidence.
</objective>

<threat_model>
Assets: private target scope, endpoint/network availability, reproducible
evidence, task history and runner resource limits.

Threats and mitigations:

- Range overlap or expansion changes what is scanned.  Normalize CIDRs,
  deduplicate exact hosts before work estimation and bind the canonical list to
  the plan digest.
- Zero duration becomes unlimited.  Treat zero only as “no extra operator
  timeout”; retain every immutable ceiling and record the first terminal ceiling.
- A scheduler exceeds rate/concurrency by retries/cancellation.  Count logical
  attempt starts at admission; use one shared semaphore/rate gate and test it
  with a fake clock/runner.
- A profile/lease/payload changes after review.  Put selectors, resolved target,
  receiver lease descriptors, payload digests and effective limits inside the
  canonical plan; revalidate before run.
- An enumerable range creates excessive work/output.  Reject estimates beyond
  the existing immutable ceilings before sockets/listeners/subprocesses exist.
</threat_model>
